== What you'll learn

In this workshop, you will:

* Monitor the Stack: Utilize Red Hat AI's out-of-the-box observability stack to track key metrics and logs of your Agentic App
* Trace Multi-Agent Executions: Track requests across multi-agent frameworks and MCP tools to understand the complete decision-making path
* From Development to Production: Automate quality monitoring with AI pipelines that run continuously on the platform

== Who this is for

This workshop is designed for site reliability engineers (SREs), Platform Engineers, and AI Developers/Engineers who want to implement end-to-end observability for multi-agent AI systems.

== Prerequisites

This workshop assumes basic familiarity with Kubernetes and AI/ML concepts.
